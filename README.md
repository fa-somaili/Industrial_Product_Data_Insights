# Industrial_Product_Data_Insights
A Python and Excel project for analysing fictional industrial product data and finding data quality issues.

# Features
-finding missing values, dup IDs, and invalid prices or stock.
-makes CSV data quality reports
-Summarises product info by category
-shows info in an Excel dashboard

# How to Run
1-Download product_data_analyzer.py and industrial_products.csv.

2-Keep both files in the same folder

3-Run the Python script 

4-look the generated data quality reports :D

# To test the checks, use industrial_products_test.csv as the input dataset at the begining.

# Project Files

product_data_analyzer.py —> Data analysis and quality checks

industrial_products.csv —> Main dataset

industrial_products_test.csv —> Test dataset with deliberate errors

data_quality_report.csv —> Summary report

product_issue_report.csv —> issue report

Industrial_Product_Data_Insights.xlsx —> Excel dashboard
